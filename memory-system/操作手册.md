# 记忆系统操作手册

> 本文档描述记忆系统的完整运作流程，供 AI 自主执行和人类理解。

---

## 一、系统架构

```
记忆系统/
├── Memory/                      # 被动沉淀轨道
│   ├── L1_情境层.yaml           # 具体事件（发生了什么）
│   ├── L2_行为层.yaml           # 行为模式（怎么做）
│   ├── L3_认知层.yaml           # 思维模式（怎么想）
│   └── L4_核心层.yaml           # 价值信念（为什么）
├── Intent/                      # 主动输入轨道
│   ├── 目标与规划.yaml
│   ├── 偏好与要求.yaml
│   └── 约束与边界.yaml
└── Meta/                        # 系统元数据
    ├── 洞察队列.yaml
    ├── 框架演变.yaml
    └── 复盘记录/
```

## 二、层级定义

### L1 情境层（Episodic Memory）— 发生了什么

**本质**：具体事件的记录

**内容**：
- 每日复盘中的 key_events
- 关键决策及其背景
- 里程碑事件
- 近期项目状态

**保留周期**：14 天滚动窗口

**沉淀条件**：
- 行为模式在 `key_insights` 中出现 → 记入 `pending_habits`
- 待每周净化时统计出现次数

---

### L2 行为层（Procedural Memory）— 怎么做

**本质**：重复出现的做事方式

**内容**：
- 工作习惯（如：先看历史再整理）
- 决策习惯（如：沟通前先想清楚）
- 时间模式（如：早上处理复杂任务）
- 工具偏好

**沉淀条件**：
- 同一模式在 L1 的 `pending_habits` 中出现 3 次以上
- 每周净化时确认

**记录格式**：
```yaml
- habit: "行为描述"
  impact: "对决策的影响"
  discovered_date: "发现日期"
  evidence: ["证据1", "证据2"]
```

---

### L3 认知层（Semantic Memory）— 怎么想

**本质**：思考问题的方式、分析框架

**内容**：
- 思维模式（如：系统性思考、结构化思维）
- 决策框架（如：分层思维、闭环思维）
- 心智模型

**沉淀条件**：
- 发现多个 L2 行为背后有共同的思维方式
- 分析行为 → 提炼共性 → 归纳为思维模式

**记录格式**：
```yaml
- pattern: "思维模式名称"
  description: "模式描述"
  related_habits: ["L2中的habit名称"]
  discovered_date: "发现日期"
  evidence: ["支撑证据"]
```

**示例推导**：
```
L2 行为：
  - "沟通前先想清楚目标"
  - "做复盘先看历史再整理"

共同点：先建立框架再执行

→ L3 新增：系统性思考 — 先框架后细节
```

---

### L4 核心层（Core Identity）— 为什么

**本质**：核心价值驱动、人生信念

**内容**：
- 核心价值观（如：追求效率、追求结果）
- 人生信念（如：长期主义）
- 决策原则

**特殊规则**：
- **仅允许人工修改**
- AI 可以建议，但必须用户确认
- 每次修改记录原因和时间

**沉淀条件**：
- 发现多个 L3 思维模式背后有稳定的价值驱动
- 需用户确认才能写入

**示例推导**：
```
L3 思维模式：
  - 系统性思考
  - 工具思维

共同价值驱动：追求效率

→ L4 验证："追求效率" 已存在，系统一致
```

## 三、沉淀流程

### 每日流程（复盘时）

1. **记录到 L1**：
   - `key_events` → 记录今天做了什么
   - `key_insights` → 识别行为模式候选

2. **更新 pending_habits**：
   - 如果 `key_insights` 中出现可复用的行为模式
   - 写入 L1 的 `pending_habits`，记录发现日期

---

### 每周流程（净化时）

**执行时机**：每周日 21:30 自动执行

**步骤**：

#### 1. 统计出现次数
```python
# 伪代码
for habit in L1.pending_habits:
    count = count_occurrences(habit, L1.entries_last_14_days)
    if count >= 3 and not exists_in_L2(habit):
        move_to_L2(habit)
```

#### 2. 分析 L2 → L3
```python
# 分析行为背后的共同思维方式
behaviors = L2.decision_habits
patterns = extract_thinking_patterns(behaviors)
for pattern in patterns:
    if not exists_in_L3(pattern):
        add_to_L3(pattern)
```

#### 3. 分析 L3 → L4 建议
```python
# 分析思维模式背后的价值驱动
thinking_patterns = L3.thinking_patterns
values = extract_value_drivers(thinking_patterns)
for value in values:
    if not exists_in_L4(value):
        suggest_L4_update(value)  # 仅建议，需用户确认
```

#### 4. 自检系统
- 反思：这套记忆系统是否有设计问题？
- 如有问题，更新 `框架演变.yaml`

#### 5. 输出周报
- 本周新增：L2 行为、L3 思维模式
- L4 更新建议（需确认）
- 下周待观察：哪些 pending_habits 需继续跟踪

---

### 每月流程

1. **回顾 L3 稳定性**
   - 本月新增的 L3 是否经得起验证？
   - 是否有需要调整或删除的？

2. **L4 确认**
   - 检查 L3 是否指向新的价值驱动
   - 如有，向用户提出 L4 更新建议

    ↓

## 五、关键判断标准

### 行为 vs 思维模式

| 判断维度 | L2 行为层 | L3 认知层 |
|----------|-----------|-----------|
| 描述内容 | 具体动作 | 思考方式 |
| 可观察性 | 外部可观察 | 内在过程 |
| 回答问题 | "你怎么做" | "你怎么想" |
| 示例 | "先看历史再整理" | "系统性思考" |

### 思维模式 vs 价值观

| 判断维度 | L3 认知层 | L4 核心层 |
|----------|-----------|-----------|
| 描述内容 | 思考框架 | 价值驱动 |
| 回答问题 | "怎么想" | "为什么" |
| 来源 | 从行为抽象 | 从思维抽象 |
| 示例 | "分层思维" | "追求效率" |

## 六、人类记忆模型参考

本系统基于认知心理学设计：

| 心理学概念 | 对应层级 |
|------------|----------|
| 情节记忆 Episodic Memory | L1 情境层 |
| 程序性记忆 Procedural Memory | L2 行为层 |
| 语义记忆 Semantic Memory | L3 认知层 |
| 自我图式 Self-Schema | L4 核心层 |

**关键原理**：
- 人类记忆通过「重复强化」和「深层加工」实现长期存储
- 具体事件经过多次提取和反思，会抽象为一般性知识
- 自我图式是最稳定的认知结构，变化最慢

## 七、AI 执行承诺

1. **每日复盘时**：自动识别行为模式候选，写入 `pending_habits`

2. **每周日 21:30**：自动执行净化流程，无需用户提醒

3. **L4 更新时**：必须向用户提出建议，等待确认

4. **系统自检**：每周反思记忆系统设计，持续迭代
