# 记忆系统使用指南

## 快速启动

### 方式一：Daily Plan Skill 自动加载

**推荐方式**：使用 Daily Plan Skill 时自动加载记忆系统

```
开始今日规划    →  自动加载记忆系统，进入脑倒空环节
开始今日复盘    →  自动加载记忆系统，引导复盘流程
```

### 方式二：手动加载记忆

```
请读取我的记忆系统（[你的项目路径]/memory-system/），加载以下内容：
1. Intent/目标与规划.yaml - 了解我的目标
2. Intent/偏好与要求.yaml - 了解我的偏好
3. Intent/约束与边界.yaml - 了解我的边界
4. Memory/L1_情境层.yaml - 了解近期上下文
5. Memory/L2_行为层.yaml - 了解我的习惯

基于以上记忆，调整你的回答方式。
```

## Daily Plan Skill 使用流程

### 快速模式（日常使用）⚡

**触发方式**：用户直接给出复盘/规划内容

**流程**：
1. 读取参考文件
2. 整理内容
3. **预览 → 等待确认 → 保存**
4. 更新 L1_情境层

### 完整模式（深度规划）🎯

**触发方式**：说「开始今日规划」或「脑倒空」

**流程**：
1. 加载记忆系统
2. 智能日期判断（周末不安排工作规划）
3. 脑倒空环节
4. 智能排序
5. 生成规划并保存
6. 更新记忆系统

## 记忆系统文件说明

### Intent 目录（主动输入）

| 文件 | 用途 | 填写时机 |
|------|------|----------|
| `目标与规划.yaml` | 核心目标、短期/中期目标、自己设定的锚点 | 首次使用、目标变化时 |
| `偏好与要求.yaml` | 复盘流程偏好、输出风格 | 首次使用、偏好变化时 |
| `约束与边界.yaml` | 决策红线、禁忌事项、规划必问问题 | 发现边界时 |

### Memory 目录（被动沉淀）

| 文件 | 用途 | 更新时机 |
|------|------|----------|
| `L1_情境层.yaml` | 近14天事件、当前项目状态 | 每次规划/复盘 |
| `L2_行为层.yaml` | 工作习惯、时间模式、决策习惯 | 发现稳定行为模式时 |
| `L3_认知层.yaml` | 思维模式、决策框架 | 发现稳定认知模式时 |
| `L4_核心层.yaml` | 核心价值观、决策原则 | 年度深度反思（人工确认） |

### Meta 目录（系统元数据）

| 文件 | 用途 |
|------|------|
| `洞察队列.yaml` | 待沉淀的洞察 |
| `框架演变.yaml` | 系统版本迭代记录 |
| `复盘记录/*.yaml` | 复盘模板 |

## 初始化步骤

### 1. 修改路径

编辑以下文件，将 `[你的项目路径]` 替换为实际路径：
- `skill/daily-plan/SKILL.md`
- `memory-system/Intent/偏好与要求.yaml`
- `memory-system/Intent/约束与边界.yaml`

### 2. 填写核心信息

打开以下文件，填写你的初始信息：

**L4_核心层.yaml**（必填）：
```yaml
core_values:
  - value: "你的核心价值观"
    description: "具体描述"
    added_date: "2026-01-01"

decision_principles:
  - principle: "你的决策原则"
    description: "具体描述"
    added_date: "2026-01-01"
```

**目标与规划.yaml**（必填）：
```yaml
core_goal: "你的核心目标"

short_term_goals:
  - goal: "短期目标"
    status: "进行中"
    priority: "高"
    notes: "备注"
    added_date: "2026-01-01"

self_anchors:
  - name: "重要不紧急的事"
    frequency: "每周"
    target: "每周推进一次"
```

**L2_行为层.yaml**（可选）：
```yaml
time_patterns:
  - pattern: "早上处理复杂任务"
    confidence: "高"
    discovered_date: "2026-01-01"
    notes: "早上精力充沛"
```

## 记忆沉淀规则

| 层级跃迁 | 触发条件 |
|----------|----------|
| L0 → L1 | 会话结束、重要事件发生 |
| L1 → L2 | 同一行为模式出现 3 次以上 |
| L2 → L3 | 发现稳定的思维模式 |
| L3 → L4 | 年度深度反思（人工确认） |

## 指令速查表

| 指令 | 用途 |
|------|------|
| `开始今日规划` | 完整模式：脑倒空 + 智能排序 |
| `做一下今天的复盘` | 快速模式：快速记录 |
| `开始今日复盘` | 深度复盘流程 |
| `脑倒空` | 进入脑倒空环节 |

---

## 注意事项

1. **必须先修改路径**：将所有 `[你的项目路径]` 替换为实际路径
2. **L4 仅人工修改**：核心价值观层只能自己修改
3. **预览后确认**：规划/复盘内容会先预览，确认后才保存
4. **周末不安排工作**：周五复盘时不自动生成周六规划
